# InterviewAi

**InterviewForge AI** is an AI-powered personalized interview preparation platform that helps candidates prepare for job interviews based on their **target job role, resume, and self-description**.

Instead of providing generic interview questions, the application analyzes the candidate's profile against the requirements of a specific job description and generates a customized interview preparation experience.

## 🚀 What It Does

The application takes three primary inputs:

* 📄 **Job Description** — Requirements, responsibilities, and skills expected for the target role.
* 📑 **Resume** — Candidate's education, skills, projects, experience, and technical background.
* 👤 **Self Description** — Candidate's personal introduction, strengths, interests, and career goals.

The AI analyzes these inputs together and generates a personalized interview report.

## ✨ Key Features

### 1. Job Description Analysis

Analyzes the target job description to identify:

* Required technical skills
* Required soft skills
* Responsibilities
* Role-specific expectations
* Important technologies and tools

### 2. Resume Analysis

Analyzes the candidate's resume to understand:

* Technical skills
* Projects
* Education
* Internship/experience
* Programming languages
* Tools and technologies

### 3. Personalized Interview Questions

Generates interview questions based on the candidate's profile and target role, including:

* 💻 Technical Questions
* 🧠 Problem-solving Questions
* 🗣️ Behavioral Questions
* 🎯 Role-specific Questions
* 📌 Resume-based Questions

### 4. Skill Gap Analysis

Compares the candidate's current skills with the requirements of the target job and identifies areas that require improvement.

Skill gaps can be categorized based on their importance and relevance to the target role.

### 5. Day-wise Preparation Plan

Creates a structured preparation roadmap based on the identified skill gaps.

The plan can include:

* Topics to study
* Technical concepts
* Practice questions
* Interview preparation tasks
* Behavioral preparation
* Revision activities

### 6. Interview Match Analysis

The AI evaluates how closely the candidate's current profile matches the target job requirements and provides an overall compatibility analysis.

## 🎯 Project Goal

The goal of InterviewForge AI is to make interview preparation more **personalized, role-specific, and data-driven**.

Rather than preparing from a generic list of interview questions, candidates can receive preparation material based on the actual requirements of the job they are targeting and the skills demonstrated in their resume.
